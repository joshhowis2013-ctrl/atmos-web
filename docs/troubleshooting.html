Troubleshooting

  • Port already in use: stop the existing server or run PORT=3001 npm start.
  • Warnings unavailable: check the endpoint, authentication header, and API key in .env.
  • Pages shows a 404: enable GitHub Pages with GitHub Actions as the source.
  • Changes do not appear: refresh the page, clear the site cache, or wait for the service worker.
  • Location does not work: allow browser location access or search for a city instead.
